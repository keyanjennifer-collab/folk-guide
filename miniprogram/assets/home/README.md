# 首页图片说明

这个目录只存放首页正式使用的图片，避免把截图或来源不明的网络图片打进小程序。

当前素材：

- `hero-forest.jpg`：首页首屏主视觉。
  - 来源：Unsplash 图片 CDN，`photo-1441974231531-c6227db76b6e`
  - 原始链接：<https://images.unsplash.com/photo-1441974231531-c6227db76b6e>
  - 许可证：Unsplash License
  - 说明：当前用于原型。正式发布前再次核对图片详情页与作者信息。

建议规格：

- `hero-forest.jpg`：首页首屏主视觉，竖图，建议 1200×1600 左右，深绿色自然植物或山林，人物和文字不宜出现在画面中央。
- `philosophy-landscape.jpg`：品牌理念过渡图，横图，建议 1200×720 左右，山水、云雾、器物局部均可。

使用外部图片时，请在本文件补充作者、来源链接和许可证。没有合适图片时，页面会使用无图的深绿色背景，不展示来源不明的占位照片。
